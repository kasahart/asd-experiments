# 第2回の検証範囲

## 推論・採点の実行記録

B0・B1・W1・SSそれぞれで、5機種の正常音5,000件とテスト音1,000件を推論し、公式評価器で採点した記録を保存しています。条件は[固定条件](02-protocol.md)、入力は[入力取得](02-inputs.md)、結果は[総合値](../results/02-summary.csv)と[機種別指標](../results/02-by-machine.csv)を参照してください。

| 実行記録 | 内容 |
|---|---|
| [B0・B1・W1](full-inference-validation.json) | 推論件数・時間、評価器の版、保存指標の確認 |
| [SS](ss-experiment.json) | 入力・設定、時間・機器、採点結果 |

## 確認した機能

- 波形処理：無音・scale・長さ、SSの式と位相、録音全6秒の処理。再描画スクリプトは実録音からWandasの図5枚を生成します。
- アプリ：正本CSVからの表生成、保存図6枚と全6秒のPCM16音声4件。保存PNG・WAVは移行前の出力とバイト一致し、音声は個別正規化・自動再生なしです。
- 公開サイト：静的HTML生成、1280・390・320 pxでの一覧からの移動・戻る操作・個別URL直接表示・対応Zenn記事リンク・手動音声再生。
- 一覧設定：slugの重複・不正な形式、ソース欠落、記事URLの検査。波形処理と合わせて全12テストが成功しています。

## 検証の限界

保存結果の表示やサイトの動作確認は、モデルの独立追試ではありません。実録音の図と音声は正常録音1例の観察用で、データ集合全体の検知スコアや雑音除去の成功率を示しません。
