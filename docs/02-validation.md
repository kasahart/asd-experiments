# 第2回の検証範囲

B0・B1・W1・SSそれぞれで、5機種の正常音5,000件とテスト音1,000件を推論し、公式評価器でテスト音を採点しています。条件は[固定条件](02-protocol.md)、入力は[入力取得](02-inputs.md)、結果は[総合値](../results/02-summary.csv)と[機種別指標](../results/02-by-machine.csv)を参照してください。

| 実行記録 | 内容 |
|---|---|
| [B0・B1・W1](full-inference-validation.json) | 推論件数・時間、評価器の版、保存指標の確認 |
| [SS](ss-experiment.json) | 入力・設定、時間・機器、採点結果 |

波形処理の無音・scale・長さ、SSの式・位相、全録音を処理し、表示・試聴に全長6秒を渡すことをテストで確認しています。marimoアプリには、Wandasで実行・確認済みの図6枚（機種別pAUC、実録音4条件、パワースペクトル重ね描き）と、同じ全6秒のPCM16音声を移しています。結果表は正本CSVから生成します。実録音の図は1例の観察用で、集合全体の検知スコアとは区別します。
